EINRICHTUNG

In wenigen Schritten in OBS.

Island Now läuft auf deinem OBS-PC. Spotify selbst kann auf jedem deiner Geräte laufen.

1. Spotify-App konfigurieren

Im Spotify Developer Dashboard eine eigene App öffnen oder „Island Now“ erstellen. Als API „Web API“ wählen. Die in der Oberfläche angezeigte Redirect-URI exakt eintragen:

http://127.0.0.1:17653/auth/callback

Kein localhost, kein zusätzlicher Slash. Bei anderem Port gilt die in der Oberfläche angezeigte URI. Änderungen im Dashboard speichern.

2. Im Browser anmelden

Unter „Verbindungen“ die Client-ID aus dem Dashboard eintragen und „Mit Spotify verbinden“ drücken. Bei Spotify mit dem gewünschten Konto anmelden. Client-Secret und Passwort werden in Island Now nicht eingegeben.

3. In OBS einfügen

Einen Titel abspielen, unter „Widget“ die Live-Vorschau prüfen und „URL kopieren“ drücken. OBS → Quelle hinzufügen → Browser. URL einfügen, Breite 800, Höhe 400. „Lokale Datei“ deaktiviert lassen. Das Widget ist transparent.

Minimieren blendet das Windows-Fenster ins Tray aus. Doppelklick auf das Symbol öffnet es wieder. „X“ beendet Island Now standardmäßig. Unter „Einstellungen → Windows-Fenster“ kannst du „X“ auf „Im Infobereich weiterlaufen“ umstellen. Das Tray-Menü bietet auch „Im Browser öffnen“. Für das eigene Fenster wird die Microsoft Edge WebView2 Runtime verwendet. Beim ersten Start eines Quellpakets lädt START-WINDOWS.cmd das Microsoft WebView2 SDK und erstellt Island-Now.exe mit dem vorhandenen .NET-Compiler; danach ist kein CMD-Fenster nötig. Fehlt eine passende Node.js-Version, lädt der Windows-Start sie automatisch mit Fortschrittsanzeige und Prüfsummenprüfung nach. Dafür wird beim ersten Start Internet benötigt; Administratorrechte sind nicht nötig. Die Laufzeit bleibt im App-Ordner unter runtime/ gespeichert. Die Spotify-Anmeldung bleibt lokal gespeichert.

Twitch Song Requests

Unter „Song Requests → Einrichtung“ die Twitch-App vom Typ Public verbinden, die Spotify-Warteschlange freigeben und einen Reward mit Texteingabe wählen. Zuschauer geben einen Suchtext wie „Levels“, „Avicii Levels“, „Songtitel - Interpret“ oder einen direkten Spotify-Track-Link ein. Spotify Premium und ein aktives Wiedergabegerät sind erforderlich. Der Schalter bleibt aus, wenn Streamer.bot den Reward verarbeitet. Unter „Chat“ bearbeitest du die Nachricht mit Vorschau, unter „Verlauf“ siehst du die letzten Einlösungen.

Wenn nichts angezeigt wird

  • Standard: nur bei Songwechsel, für 15 Sekunden. Für durchgehende Anzeige „Dauerhaft“ wählen.
  • Bei Pause und gestoppter Wiedergabe kann das Widget absichtlich transparent sein.
  • Im Developer Dashboard weitere Spotify-Konten vorab freischalten. Neue Entwicklungs-Apps erlauben fünf Nutzer; der App-Inhaber braucht Premium.
  • Unter „Dein Look“ stehen auch Cyberpunk, dein klassischer Forza-Stil, Winamp Classic und WoW-Questlog zur Auswahl. Winamp Classic übernimmt das originale Player-Format mit Pixel-Schrift, Segment-Uhr und grünem Display. Im klassischen Fenster gibt es kein Albumcover; Cover-Farben sind weiterhin möglich. Pegelbalken und Tasten sind dekorativ. Die Option „Akzentfarbe aus Cover“ übernimmt den Farbton des Albums mit kräftigerem Akzent. Unter „Bewegung“ sind Ein-/Ausblenden und Titel-/Coverwechsel getrennt einstellbar.
  • Bei abgelaufener oder widerrufener Freigabe erneut verbinden. Bei 429 wartet die Anwendung automatisch.
  • Nach Neustart der Anwendung die Browseroberfläche neu laden, falls sie eine abgelaufene Sitzung meldet.

Andere Personen können das ZIP auf ihrem eigenen PC mit eigener Client-ID verwenden. Der persönliche Ordner .data enthält die Anmeldung und gehört nicht in ein weitergegebenes Paket. Eine zentrale öffentlich gehostete Mehrnutzer-Version ist in diesem lokalen Paket nicht enthalten.
